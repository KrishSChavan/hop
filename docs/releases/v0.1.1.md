A quick fix after the first test between the two laptops, and one change you asked for. Install it on **both** computers.

## What's new

- **Moving to the other computer no longer stutters.** In 0.1.0 the cursor often bounced back from the edge, sometimes dozens of times, before it stayed on the other computer. The cause was on the Mac: when the cursor left, Hop moved the Mac's hidden cursor to the middle of the screen, and macOS counted that jump as mouse movement. Hop passed it on, so the cursor went straight back. Hop now leaves the hidden cursor where it crossed, and takes out any such jump that is left.
- **Keys stay as labelled.** With the Mac's keyboard on the PC, use the PC's shortcuts: Ctrl+C copies and Ctrl+V pastes. The Mac's Cmd key acts as the PC's Windows key. With the PC's keyboard on the Mac, the Windows key acts as Cmd, so Windows key + C copies. (In 0.1.0, Cmd and Ctrl traded places between the computers. A choice in the app to bring that back comes in the next version.) The computer that receives the keys decides, so update both.
- Hop's log now notes how long the other computer took to answer each crossing. If moving across still feels slow, that number shows whether the other computer's Wi-Fi was asleep.

## Which file

- **Hop-macOS.zip** is for the Mac. It holds Hop.app.
- **Hop-Windows.zip** is for the PC. It holds Hop.exe and a short README.txt.

You don't need the "Source code" files. Your pairing and settings stay as they are: update as in step 7 of the [install guide](https://github.com/KrishSChavan/hop/blob/v0.1.1/docs/INSTALL.md).

## Coming next

The text clipboard (copy on one computer, paste on the other), sending files by dragging them to the edge of the screen, hiding the PC's cursor while you work on the Mac, and the shortcuts choice in the app.

## Known limits

- New: if the Mac's Dock (or menu bar) hides itself and sits on the side of the screen that faces the PC, it stays shown while you use the PC, because the Mac's hidden cursor now waits at that edge.

The same as 0.1.0:
- Hop is not signed by a known publisher, and the Mac app is not notarized by Apple, so each computer warns about Hop the first time it opens. On a PC where Smart App Control is on, Windows blocks Hop.exe outright.
- The Mac app runs only on Macs with Apple silicon (M1 or later).
- While a password field on the Mac has focus, keys typed for the PC may go into that field instead. Click somewhere else on the Mac before moving to the PC.
- Signing out of Windows or shutting it down while sharing ends Hop without its usual goodbye; the Mac then takes about 1.5 seconds to take its keyboard and mouse back.
