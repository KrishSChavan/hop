The first release of the Hop app. One window on each computer pairs your Mac and your Windows PC, says where each one sits on the desk, and shares one keyboard and mouse between them.

## What it does

- Push the cursor past the screen edge that faces the other computer, and it carries on there. The keyboard follows. It works both ways.
- Shortcuts follow you: Cmd+C typed on the Mac arrives on the PC as Ctrl+C, and Ctrl+C typed on the PC arrives on the Mac as Cmd+C.
- The two computers pair once, with a six-digit code. After that they find each other on the home Wi-Fi by themselves, and only each other can connect. Everything between them is encrypted.
- The emergency keys bring the keyboard and mouse back at once: Control + Option + Shift + Escape on the Mac, Ctrl + Alt + Shift + Esc on the PC (the keys on the left).
- Closing Hop's window stops sharing, and gives the keyboard and mouse back first.
- The log never contains what you type or copy, or pairing codes.

## Which file

- **Hop-macOS.zip** is for the Mac. It holds Hop.app.
- **Hop-Windows.zip** is for the PC. It holds Hop.exe and a short README.txt. Hop.exe needs nothing else installed.

You don't need the "Source code" files. Install the same version on both computers.

The [install guide](https://github.com/KrishSChavan/hop/blob/v0.1.0/docs/INSTALL.md) walks through the first start on each computer, pairing, and everyday use.

## Known limits

- Hop is not signed by a known publisher, and the Mac app is not notarized by Apple. So the browser may warn about the download, and each computer warns about Hop the first time it opens. The install guide shows how to get past that.
- On a PC where Smart App Control is on, Windows blocks Hop.exe outright, because it is not signed. Hop runs there only once Smart App Control is turned off; the install guide says what to weigh first.
- The Mac app runs only on Macs with Apple silicon (M1 or later).
- Hop shares with one other computer at a time.
- While a password field on the Mac has focus, keys typed for the PC may go into that field instead. Click somewhere else on the Mac before moving to the PC.
- Signing out of Windows or shutting it down while sharing ends Hop without its usual goodbye. If the Mac's keyboard and mouse were controlling the PC at that moment, the Mac takes about 1.5 seconds to notice and take them back.
- Not in this release yet: the text clipboard, sending files, a menu-bar or tray icon, starting at login, and a Windows installer.

This is the first release that runs on both computers together. If anything seems off, the Activity list and **Open log folder** in Hop show what happened.
