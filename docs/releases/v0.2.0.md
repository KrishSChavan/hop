Copy and paste between the computers, sending files by dropping them at the screen edge, and a tidier cursor. Install it on **both** computers.

## What's new

- **Copy and paste.** Copy text on one computer, move the cursor across, and paste with that computer's own shortcut (Ctrl+V on the PC, Cmd+V on the Mac). The text goes along when the cursor crosses. Text from a password manager, and text over about a million characters, is never sent, and copied text never goes into Hop's log.
- **Send files.** Drag files from Finder or File Explorer right up against the edge of the screen that faces the other computer. On the Mac, a thin line along that edge lights up as the files get close. When they reach the edge, a box appears: "Drop to send to Windows PC". Let go anywhere on the box. The files are copied (never moved) to **Downloads › Hop Received** on the other computer, and that folder opens there.
  - The first time files arrive on the Mac, macOS asks, on the Mac's screen, whether Hop may use the Downloads folder: click **Allow** within 2 minutes, or drop the files again afterwards.
  - Files that arrive are marked as downloaded, so opening an app or document from them gets your computer's usual checks.
- **The cursor you leave behind is hidden.** When you move from the PC back to the Mac, the PC's cursor disappears until you use the PC's own mouse or trackpad, and the other way round.
- **Shortcuts.** Hop's window has a new **Shortcuts** choice: keep keys as labelled (the default: with the Mac's keyboard on the PC, Ctrl+V pastes), or swap Cmd and Ctrl. Each computer's choice covers the other computer's keyboard typing on it.
- **Quicker first crossing on Wi-Fi.** A laptop's Wi-Fi dozes when it is idle, which could hold the first move across for a few tenths of a second. Hop now wakes the other computer's Wi-Fi as the cursor heads for the edge.
- Hop's Activity list says when copy and paste is working, when files go or arrive, and why, if they could not.

## Which file

- **Hop-macOS.zip** is for the Mac. It holds Hop.app.
- **Hop-Windows.zip** is for the PC. It holds Hop.exe and a short README.txt.

You don't need the "Source code" files. Your pairing and settings stay as they are: update as in step 7 of the [install guide](https://github.com/KrishSChavan/hop/blob/v0.2.0/docs/INSTALL.md), which also covers copy and paste and sending files.

## Known limits

- The cursor does not cross while you hold a mouse button, so files are dropped at the edge, not dragged onto the other screen. They always go to Downloads › Hop Received.
- Only real files can be sent: not folders, and not items that only exist inside an app (Mail or Outlook attachments, Photos).
- Copied text goes along when the cursor moves across. Switching by just using the other computer's own mouse or keyboard does not carry it, and text copied before you clicked Start sharing stays behind: copy it again.
- If the Mac's Dock (or menu bar) hides itself and sits on the side that faces the PC, it stays shown while you use the PC.
- The same as before: Hop is not signed by a known publisher or notarized, so each computer warns about it the first time it opens, and on a PC with Smart App Control on, Windows blocks Hop.exe. The Mac app needs Apple silicon. While a password field on the Mac has focus, keys meant for the PC may go into it.
